## 概要
- 架空の小さなお店の商品一覧とカートを、1台のブラウザ内で動く形で作る
- 会員登録や支払いは行わず、商品閲覧・絞り込み・カート管理・お気に入り管理をまとめて実装する
- 商品データは JSON で管理し、JavaScript から fetch で読み込む
- カートとお気に入りは別の状態として扱い、ページを再読み込みしても localStorage に保存された内容が残る

## 機能要件
- 商品一覧には 10 件以上の商品を表示し、商品名・税抜き価格・カテゴリ・画像（色付き四角で代用可）を出す
- 商品データは products.json に保存し、fetch で取得する
- カテゴリで絞り込みを行い、「すべて」に戻せる
- 商品一覧から商品をカートに入れる／カートから外すことができる
- カート内の商品数量を + / - で 1〜99 の範囲で調整できる
- 数量が 1 の状態で - を押すと、その商品はカートから削除される
- 税抜き合計と税込み合計を表示し、3 桁ごとにカンマ区切りを行う
- 税込み合計は「税抜き合計 × 1.1」の小数点以下を切り捨てる
- 商品一覧からお気に入りの追加・解除ができる
- お気に入り一覧には、お気に入りに登録した商品だけを表示する
- 画面幅が 375px のときでも横スクロールせずに操作できる

## 受け入れ条件
- 1,280円、980円、395円の商品を1個ずつ入れると、税抜きの合計が 2,655円、税込みの合計が 2,920円と表示される
- 数量が 1 のときに - を押すと、その商品がカートから消える。99 のときに + を押しても増えない
- 絞り込みを切り替えても、カートの中身は変わらない
- お気に入りに登録した商品だけが、お気に入りの一覧に並ぶ
- 再読み込みしても、カートとお気に入りが残っている
- カートが空のときは「カートは空です」などの表示が出る
- ブラウザの開発者ツールで画面の幅を 375px にしても、横にスクロールせずにカートの操作ができる

## 確認手順
1. ページを開く
2. 商品一覧で「入れる」を押して、カートに商品が追加されることを確認する
3. カート内で + / - を使い、数量が 1 のときに - を押したら商品が削除されることを確認する
4. 99 の状態で + を押しても増えないことを確認する
5. カテゴリを切り替えても、カートの中身が変わらないことを確認する
6. 商品一覧からお気に入りの追加・解除ができることを確認する
7. お気に入りタブを開いて、登録済み商品だけが表示されることを確認する
8. 1,280円、980円、395円の商品を1個ずつカートに入れ、税抜き合計が 2,655円、税込み合計が 2,920円になることを確認する
9. ブラウザを再読み込みして、カートとお気に入りの状態が残っていることを確認する
