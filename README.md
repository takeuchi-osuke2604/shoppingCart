## 課題内容
商品を選んでカートに入れ、合計金額を確かめるまでのお店のページを作ります。

## 作るもの 
- 架空の小さなお店（例：手作り雑貨の店）の商品ページとカート 
- 会員登録、ログイン、支払いは作らない。1台のブラウザの中で完結させる 
- 一覧、絞り込み、カート、お気に入り、保存を組み合わせる応用のお題です

## 必要な機能 
- 商品一覧：10件以上。商品名、税抜きの価格、カテゴリ、画像を出す（画像は色を付けた四角でもよい）。うち3件の価格は 1,280円、980円、395円にする 
- 商品のデータは products.json というファイルに書き、fetch で読み込む（HTMLファイルをダブルクリックで開くと読み込めないので、自分のパソコンで確かめるときは VS Code の Live Server などで開く） 
- カテゴリでの絞り込み（「すべて」に戻せる） 
- カート：商品を入れる、＋と−のボタンで数量を1〜99の間で変える（数量が1のときに−を押すとカートから外れる）、カートから外す 
- 金額：税抜きの合計と、税込みの合計を3桁ごとにカンマで区切って出す。税込みの合計は「税抜きの合計 × 1.1」の1円未満を切り捨てる 
- お気に入り：登録と解除、お気に入りだけを並べた一覧 
- ページを再読み込みしても、カートとお気に入りが残る（ブラウザに保存する localStorage を使う）

## できたと言える状態 
- 1,280円、980円、395円の商品を1個ずつ入れると、税抜きの合計が 2,655円、税込みの合計が 2,920円と表示される 
- 数量が1のときに−を押すと、その商品がカートから消える。99のときに＋を押しても増えない 
- 絞り込みを切り替えても、カートの中身は変わらない 
- お気に入りに登録した商品だけが、お気に入りの一覧に並ぶ 
- 再読み込みしても、カートとお気に入りが残っている 
- カートが空のときは「カートは空です」などの表示が出る 
- ブラウザの開発者ツールで画面の幅を375pxにしても、横にスクロールせずにカートの操作ができる
